# React Component Template (placeholder)

This folder will hold the scaffolding template for a standard feature component: the
component file, its styles, its test, and an optional custom hook for its logic.

No template code has been added yet - this is a structural placeholder. When the
`generate-react-components` skill is exercised, add the actual template files here, e.g.:

- `ComponentName.jsx` - the component itself (functional component, hooks-based)
- `ComponentName.module.css` - scoped styles for the component
- `ComponentName.test.jsx` - unit/component tests (React Testing Library)
- `useComponentName.js` - optional custom hook holding the component's stateful logic
- `index.js` - re-exports the component for cleaner imports
