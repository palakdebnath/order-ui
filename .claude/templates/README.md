# Templates

Scaffolding references used by the `generate-react-components` skill when implementing new
features. No React code is included yet - each subfolder's README describes the intended
structure and conventions; actual template files will be added when implementation starts.

## Available Templates

- `react-component/` - conventions for a standard feature component (component + styles +
  test + optional hook), following React/JSX naming and file-organization conventions.
